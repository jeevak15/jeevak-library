# Library Management System in C

A simple and beginner-friendly **Library Management System** built using the **C programming language**.

This project helps beginners learn:

- Structures
- Functions
- Arrays
- File Handling
- Searching
- Modular Programming

The program stores book records permanently using a text file (`books.txt`).

---

# Features

- Add New Books
- View All Books
- Search Books by ID
- Delete Books
- Save Data in File
- Menu-Driven Interface

---

# Technologies Used

- C Language
- GCC Compiler
- Text File Handling
